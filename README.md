# 🎮  주식 투자 시뮬레이션 교육 게임

실제 주식 거래를 모방한 교육용 플랫폼으로, 안전한 환경에서 투자 경험을 쌓을 수 있습니다.

## 🎯 게임 개요

- **시점 고정**: 2020년 1월 ~ 2024년 12월
- **진행 방식**: 반기별 업데이트 (총 10라운드)
- **목표**: 투자 지식 습득과 포트폴리오 성장

## 🚀 주요 기능

### 📈 주식 거래 시스템
- 매수/매도 기능
- 실시간 주식 조회
- 포트폴리오 관리
- 실제 주식 데이터 기반

### 📰 뉴스 시스템
- 거시 경제 뉴스 (반기별 업데이트)
- 투자 결정에 영향을 주는 정보 제공

### 🧠 퀴즈 시스템
- 데일리 투자 퀴즈
- 투자 교육 콘텐츠

### 🤖 챗봇
- 투자 상담 및 도움말
- 게임 가이드 제공

### 🏆 랭킹 시스템
- 사용자 순위표
- 성과 비교 및 경쟁 요소

### 👤 사용자 관리
- 로그인/회원가입
- 프로필 관리

## 🛠 기술 아키텍처

### Frontend
- **React** + **JavaScript** + **Tailwind CSS**
- 모던한 웹 인터페이스
- 반응형 디자인
- 게임화된 요소들 (GIF 애니메이션)

### Backend
- **Python FastAPI** + **SQLAlchemy**
- RESTful API 제공
- 비동기 처리

### Database
- **SQLite** (aiosqlite 사용)

### Proxy
- **Node.js** 기반 프록시 서버

## 📁 프로젝트 구조

```
├── front/           # React 프론트엔드
├── back/            # Python 백엔드
├── Docs/            # 문서 및 이미지 자료
└── README.md        # 프로젝트 설명서
```

## 🎮 게임 실행 방법

### Frontend 실행
```bash
cd front
npm install
npm run dev
```

### Backend 실행
```bash
cd back
pip install -r requirements.txt
uvicorn main:app --reload
```

## 🎯 게임 목표

1. **투자 학습**: 실제 주식 시장 환경에서 투자 지식 습득
2. **리스크 관리**: 다양한 투자 전략 실험
3. **포트폴리오 최적화**: 수익률 극대화
4. **경쟁**: 다른 플레이어들과의 랭킹 경쟁

즐거운 투자 게임 되세요! 📈💰
